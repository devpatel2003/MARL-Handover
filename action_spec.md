# Action Spec — `TwoArmHandover` (robosuite)

Generated by inspecting `env.action_dim`, `env.action_spec`, and each robot's
`composite_controller._action_split_indexes` for the config used in `scratch/explore_env.py`
(`robots=["Sawyer", "Panda"]`, `env_configuration="opposed"`, `controller="BASIC"`).

## Overview

- **`env.action_dim` = 14** total.
- Split evenly across the two robots: **7 per robot**.
- All values are normalized to `[-1, 1]` (deltas relative to current pose / gripper state).
- `env.step(action)` expects one flat concatenated vector:
  `action = [robot0_action (7,), robot1_action (7,)]`

## Per-robot breakdown (7-dim each)

Confirmed via `robot.composite_controller._action_split_indexes`:
`OrderedDict({'right': (0, 6), 'right_gripper': (6, 7)})`

| Index range | Part | Dim | Description |
|---|---|---|---|
| `[0:6]` | `right` (arm) | 6 | Delta pose command for the arm's OSC-style controller: 3 translation deltas (x, y, z) + 3 rotation deltas. Controller `input_type` is `delta`, so these are increments relative to current eef pose, not absolute targets. |
| `[6:7]` | `right_gripper` | 1 | Scalar gripper command: -1 = open, +1 = close. Internally mirrored to both finger actuators (gripper has `control_dim=2` at the actuator level, but only 1 input slot in the action vector since the two fingers move symmetrically). |

Robot naming: `robot0` = Sawyer, `robot1` = Panda (order follows the `robots=[...]` list).

## Notes for the MARL setup

- Each agent's policy naturally outputs a 7-dim action matching its own robot's slice.
- No cross-agent action coupling at the env level — the composite action is just a
  concatenation, so per-agent policies can be trained independently and their actions
  stitched together before calling `env.step()`.
- If controller config changes (e.g. `IK_POSE`, joint-space control instead of `OSC_POSE`),
  the 6-dim arm portion's meaning changes accordingly — re-verify `_action_split_indexes`
  and `input_type` if the controller type in `configs/*.yaml` is changed from `BASIC`.
